# Игровое меню и постановка сцены

## Игрок

Экспортированный `RinvaPlayer.exe` открывает главное меню: **Продолжить**, **Новая игра**, **Сохранения**, **Загрузить**, **Настройки**, **Выход**. В предпросмотре редактора F5 сразу запускает историю; **Меню / Esc** открывает те же страницы. Из меню редакторского предпросмотра доступно **В редактор**.

Меню приостанавливает печатание, автоматическое чтение и аудиоканалы. Закрытие меню продолжает текущий кадр, не выбирает ответ и не меняет текст. **F11** включает полный экран на текущем мониторе; повторное нажатие восстанавливает прежнее положение окна.

Настройки: скорость печатания, независимая громкость музыки/эффектов/голоса, светлое или тёмное окно диалога, размер текста 100/125/150%. Язык интерфейса и тема доступны в меню. Это настройки читателя, а не перевод или изменение авторского сценария.

## Сохранения

- Шесть ручных слотов выбираются на странице **Сохранения**; существующий слот перезаписывается после подтверждения.
- **F6** записывает отдельный быстрый слот, **F9** его загружает. Поддерживается чтение прежнего одиночного сохранения, если новый быстрый слот ещё пуст.
- Прогресс автоматически записывается в собственный слот при изменении позиции, не чаще одного раза в 10 секунд. Закрытие игры дожидается записи последнего прогресса. Автокопия проекта редактора остаётся отдельной системой.
- Каждый слот содержит дату/время, имя сцены и миниатюру 320×180. Файл записывается атомарно вместе с миниатюрой; `.bak` хранит предыдущую запись.
- Повреждённый или несовместимый слот не загружается; другие слоты остаются доступны. Совместимость со старой версией сценария по-прежнему проверяется строго — миграции прогресса в этом обновлении нет.

Файлы находятся в `%LOCALAPPDATA%/Rinva/saves/game-…`. Каталог определяется идентификатором проекта, поэтому перенос игры в другую папку не теряет прогресс. Проверка принадлежности и версии выполняется также внутри файла. Фоновая запись не блокирует меню; успешное сохранение подтверждается только после завершения записи.

## Постановка сцены

1. Откройте **Предпросмотр** и раздел **Персонажи** в правом инспекторе.
2. Добавьте персонажа и изображение эмоции, нажмите **На сцену**. Старое одиночное поле «Персонаж…» не создаёт размещение из каталога.
3. Выберите персонажа на холсте или в списке **Персонажи в сцене**. При наложении щелчок выбирает верхнее размещение по прямоугольнику изображения; список позволяет выбрать перекрытое.
4. Перетаскивайте тело для перемещения, любой из четырёх углов — для равномерного масштаба. Опора масштаба — нижний центр персонажа; пропорции изображения сохраняются.
5. **Сетка 5%** показывает направляющие и округляет координаты при перетаскивании. Стрелки двигают выбранного персонажа на 1%, Shift+стрелки — на 10%. Поля X/Y/масштаба остаются точной альтернативой мыши.
6. **На передний план / На задний план** меняют порядок слоёв. Все изменения участвуют в undo/redo.

Во время жеста меняется только временное отображение и значения в инспекторе. Отпускание кнопки создаёт один шаг отмены. Esc, потеря захвата, переключение инструмента, изменение размера окна и потеря активности отменяют незавершённый жест. Автосохранение не записывает промежуточное положение. В режиме постановки окно реплики скрыто, чтобы не перекрывать персонажей.

## Проверка

Сборка и запуск: `cargo run --locked -p rinva-desktop`. Полная нативная проверка: `rinva.exe --smoke-test smoke-output`. После неё экспортированная тестовая игра доступна в `smoke-output/standalone/` и проверяется командой `RinvaPlayer.exe --smoke-player smoke-player-output`.

Скриншоты `stage-*.png` и `player-*.png` снимаются с настоящих окон во время теста. Геометрические персонажи — тестовые изображения, а не иллюстрации для готовой новеллы.
