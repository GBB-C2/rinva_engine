# Проверка настольного редактора

Автоматизация: `cargo test --workspace` и `rinva.exe --smoke-test smoke-output`.

Перед выпуском пользовательской версии выполнить следующие ручные проверки на Windows 10 и Windows 11. Пункты ниже являются планом проверки, а не утверждением о выполненных испытаниях.

| Область | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| Редактирование | Ввести русский/японский текст, вставить несколько абзацев, переместить курсор | IME, выделение и буфер обмена работают; курсор не прыгает |
| Отмена | Изменить поле, перейти к другому полю, нажать «Отмена» | Один сеанс правки отменяется целиком |
| Фокус | Пройти весь интерфейс Tab/Shift+Tab; открыть и отменить список | Фокус виден; отмена не меняет значение |
| Развилки | Добавить три ответа и пройти каждый | Выбранный ответ ведёт в соответствующую сцену |
| Ошибки | Удалить изображение из папки, открыть проект, нажать F5 | Есть понятная ошибка, редактор и текст остаются доступны |
| Сохранение | Отменить диалог, выбрать недоступную папку, закрыть с правками | Отмена/ошибка не закрывает документ и не уничтожает исходник |
| Автосохранение | Изменить текст, подождать 15 секунд, завершить процесс через диспетчер задач, запустить снова | Предложено восстановление, восстановленный проект помечен несохранённым |
| Несколько окон | Открыть два редактора и изменить разные проекты | Каждый пишет свою копию; живые сеансы не предлагаются к восстановлению |
| Конфликт восстановления | После сбоя изменить исходный файл другим редактором и восстановить автокопию | Восстановленный текст открывается как новая копия; исходник не перезаписывается |
| Перенос | «Сохранить как» в новую папку, затем перенести эту папку | Все используемые изображения доступны |
| Экспорт | Создать сборку, запустить отдельно, перенести на другой ПК | Игра работает без установки Rust; существующая папка не перезаписывается |
| Темы | Переключить обе темы во время редактирования и игры | Текст, выбор, история и документ сохранены |
| DPI | 100/125/150/200%, перенос между мониторами | Текст читается, элементы не перекрываются; проверить небольшой экран |
| Доступность | Narrator, клавиатура, системный высокий контраст | Все основные действия доступны; выявленные ограничения документировать |
| Длинный текст | 4000 символов, длинное имя сцены, много сцен | Списки и текст прокручиваются, полный текст доступен под игровой сценой |
| Поиск | Найти повторяющийся текст, эмодзи и CJK; переключить область, нажать F3/Enter/Esc | Выделяется точное совпадение; сценарий и undo не меняются |
| Проверка | Пустая реплика, потерянный переход, отсутствующий фон, недоступная сцена | Ошибки и предупреждения различаются; переход открывает нужное поле |
| Устаревшие результаты | Изменить или удалить найденную реплику до перехода по старому результату | Список обновляется, редактор не переходит к чужому полю |
| IME и поиск | Подтвердить/отменить живую композицию Enter/Esc внутри поискового поля | Клавиши обрабатывает IME, панель не закрывается до завершения композиции |

Системные диалоги и некоторые штатные элементы Windows имеют собственное оформление. Собственные поверхности редактора проверяются отдельно от оформления ОС.

Дополнения: автоматизированный Windows smoke переключает все пять языков, проверяет наличие кириллических, латинских и CJK-глифов, отмену выбора языка, сохранение настройки, перемещение/отмену/потерю захвата узла, создание и удаление связи, соответствие перехода проигрывателю, undo/redo, автокомпоновку и прокрутку длинного текста и списка мышью/клавиатурой. Проверяется согласованность выделенного выхода после перестановки и удаления ответов и копирования сцены. Снимки `nodes-*.png`, `nodes-light.png`, `scrollbars.png` и `editor-small-ja.png` сохраняются в артефакте `native-smoke`; полнота отрисовки текста и предпросмотра после смены темы проверяется по снимкам реальных элементов окна.

Перед выпуском дополнительно проверить живую композицию IME на корейской, японской и китайской раскладках, точность переводов носителями языка, высокую контрастность, сенсорную панель и перенос холста между мониторами 100/200%. Граф имеет клавиатурные и нативные альтернативы для выбора сцен и изменения связей; отдельная доступная иерархия узлов для экранного диктора пока не реализована.

Нативные проверки поиска выполняют переход из строки запроса, выделение UTF-16 после эмодзи и перевода строки, перебор результатов без потери фокуса, отмену, фильтры, защиту устаревшего результата и исправление проблем через инспектор. Защита горячих клавиш проверяется синтетическими уведомлениями начала/конца композиции; это не заменяет живую проверку IME. Поиск снят на всех пяти языках, панель проблем — в обеих темах.
