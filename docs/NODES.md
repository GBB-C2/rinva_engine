# Диалоги, механики и интерфейс через ноды

По умолчанию предпросмотр сцены расположен сверху, граф — снизу. Перетащите разделитель между ними, чтобы изменить высоту просмотра. Escape отменяет перетаскивание; положение после отпускания мыши сохраняется. Слева остаётся список сцен, справа — инспектор выбранной ноды. Кнопка «Предпросмотр» открывает привычный список реплик под сценой; «Ноды» возвращает граф.

Палитра редактора нейтральная в обеих темах: панели, поля, выделение, связи, кнопки и списки не используют синий акцент. Цвет импортированных изображений сохраняется.

## Собрать экран без кода

Откройте `examples/node-ui.rinva` и нажмите F5. Кнопка «+1 монета» запускает ноду изменения переменной и заново собирает меню. «Начать историю» убирает меню и открывает диалог; условие выбирает продолжение по числу монет.

| Нода | Поведение |
| --- | --- |
| Диалог / Выбор | Реплики персонажей и варианты ответа |
| Переменная / Условие | Изменение целого числа и ветвление |
| Музыка / Конец | Звук и завершение истории |
| UI · Панель | Добавляет прямоугольную подложку |
| UI · Текст | Добавляет надпись; `{coins}` показывает значение переменной `coins` |
| UI · Кнопка | Добавляет настоящую кнопку с фокусом и управлением с клавиатуры |
| UI · Очистить | Удаляет все добавленные элементы экрана |
| UI · Экран | Ожидает нажатия; автоматическое выполнение здесь останавливается |

1. Выберите тип в списке над графом и нажмите «+ Узел».
2. Для UI-ноды откроется инспектор «Интерфейс». Задайте текст и прямоугольник в процентах от кадра: X/Y — левый верхний угол, ширина/высота — размеры. Нажмите «Применить». Это один шаг отмены.
3. Соедините выход «Далее» с очередным элементом. Завершите цепочку нодой «UI · Экран».
4. У кнопки соедините отдельный выход «Нажатие» с диалогом, условием или изменением переменной. Этот выход срабатывает только по нажатию; создание кнопки продолжает цепочку через «Далее».
5. Перед переходом от меню к истории поставьте «UI · Очистить», если меню больше не нужно. Без очистки интерфейс остаётся поверх последующих сцен.
6. У экрана можно задать «После сцены»: тогда доступна обычная кнопка «Далее». Без перехода экран ждёт собственные кнопки.

Текст, положение и связь кнопки сохраняются в `.rinva`. F5 проверяет обязательные поля и назначения переходов. Поиск находит надписи интерфейса, а диагностика открывает нужный инспектор. Удаление ноды, на которую ссылается кнопка, блокируется до изменения связи.

## Состояние и границы первой версии

Пройденные UI-ноды добавляются в состояние проигрывателя. Повторное исполнение той же ноды не создаёт дубликат. Сохранение игры и возврат назад восстанавливают экран вместе с переменными. Ошибка арифметики или слишком длинная автоматическая цепочка отменяет переход целиком.

На экране поддерживается до 64 элементов. Панели и надписи рисуются в порядке создания, кнопки находятся поверх них. Размеры привязаны к кадру 16:9 и корректируются при изменении окна и DPI. Текст использует встроенные шрифты; вложенные контейнеры, отдельные стили элементов, анимации и привязки к краям пока не реализованы.

В редакторе верхняя область показывает выбранную цепочку создания интерфейса: обратный обход останавливается на очистке или неоднозначном соединении нескольких веток. Это предпросмотр компоновки, а точное состояние переменных и ветвлений проверяется запуском F5. «Отсюда» начинает выполнение с выбранной ноды, поэтому для проверки всего меню выбирайте начало цепочки.

Старые проекты не требуют миграции: новые поля необязательны. Добавление или изменение UI влияет на подпись игрового сценария, поэтому старый прогресс для изменённой истории отклоняется существующей проверкой версии.
